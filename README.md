# Mountain of Fire and Miracles Ministries (MFM) - Uyo
Official website for Mountain of Fire and Miracles Ministries, South-South 3 Mega Region HQ, Uyo, Akwa Ibom State, Nigeria.

## Features
- **Header**: Official MFM Logo, Regional Title & Subtitle, and collapsible drawer navigation menu.
- **Hero Carousel Banner**: Horizontal swipeable/scrollable announcements and service highlights with responsive pagination indicators.
- **Daily Word & Devotional**: Inspirational scripture and pastoral messages.
- **Weekly Worship Schedule**: Sunday services, Wednesday Manna Water service, and Tuesday counseling sessions.
- **Floating Action Button (FAB)**: Quick-access circular phone button opening pastoral prayer & counseling helpline numbers.
- **Bottom Navigation Bar**: 5-tab responsive navigation bar (Home, Events, Gallery, Announcements, More) with active tab indicators and SVG icons.
- **Theme**: Signature MFM purple (`#800080`) with high-contrast accessibility.
